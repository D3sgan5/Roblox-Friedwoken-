# Roblox-Friedwoken-
  My attempt on making combat like in Deepwoken.
  The system has a parry, fint, ragdoll, heavy attack, run, block and etc. 

  Hello. To setup and see the system yourself all you need is:
  1. Download the release .rbxl
  2. Open it in Roblox Studio
  3. Upload all animations in Rig and paste them in their places in ReplicatedStorage
  4. Press Play
  5. Done
